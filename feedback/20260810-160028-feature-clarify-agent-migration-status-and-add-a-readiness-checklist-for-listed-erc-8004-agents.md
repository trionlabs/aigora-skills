### Problem / motivation
As a builder with an ERC-8004 agent already listed on Aigora, one point of friction was understanding the difference between "Listed" and "Migrate to Aigora."

It wasn't immediately clear whether migration was required, what changes after migrating, what new capabilities it unlocks, or whether my existing agent ID/profile would remain the same.

### Proposed feature
I'd suggest adding a clear agent status/readiness panel to "My Agents" that shows:
where the agent is currently registered/listed;
what "Listed" means;
what "Migrate to Aigora" actually changes;
whether migration is optional or required for specific features;
which setup steps are already complete;
remaining actions such as services, payout wallet, profile details, and marketplace readiness.

A short checklist with something like "Your agent is ready for X, but still needs Y for Z" would make onboarding much clearer and reduce the chance of builders creating duplicate registrations or taking unnecessary onchain actions.
